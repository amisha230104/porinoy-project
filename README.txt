Porinoy Files:

porinoy_app.py: Streamlit application
porinoy.html: Static HTML version
images/: folder containing images required
matrimonial_ads_cleaned.json: sample data to be uploaded in the streamlit application

Requirements:

Python 3.10 or later (recommended)
Streamlit installed

Install Streamlit (if required):

	pip install streamlit

Run the application from the project directory:

	streamlit run porinoy_app.py
